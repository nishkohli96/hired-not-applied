# Regional resume / CV formats

Defaults only. The user's stated preference always wins.

## US / Canada ("resume")
- 1 page under ~10 years experience, 2 pages max.
- Header: name, city/state, phone, email, LinkedIn, portfolio/GitHub.
- No photo, DOB, marital status, nationality, full address.
- Sections: Summary → Skills → Experience → Projects (optional) → Education → Certifications.

## UK / Ireland ("CV")
- 2 pages. No photo.
- Personal profile (3–4 lines) at top. "References available on request" optional.

## Europe (DE, FR, NL, Nordics, etc.)
- 1–2 pages. Europass accepted but a clean modern CV usually reads better in private sector.
- Photo common in DE/AT/CH/FR; optional elsewhere. Language skills with CEFR levels (B2, C1).

## Gulf / Middle East (UAE, KSA, Qatar, Kuwait, Oman, Bahrain)
- 2–3 pages. Professional photo common.
- Personal details block: nationality, current location, visa status, driving license (if relevant), notice period / availability, languages.
- Career summary then key skills, experience with company context (industry, size, region), education, certifications.
- Mention GCC experience or regional exposure prominently if present.

## India
- 2 pages. Photo optional.
- Include current location, notice period, total experience. Avoid DOB, marital status, father's name unless the employer asks.

## Australia / New Zealand
- 2–3 pages. No photo.
- State work rights up front (e.g. "Full working rights" or visa type) only if the user provides it.
- Referees section (or "available on request").

## Singapore / Southeast Asia
- 2 pages. Photo optional.
- Work pass status if the user provides it; expected salary only when the application asks.

## Academic CV (any region)
- No length limit. Publications, grants, teaching, conferences, service. Use the field's citation style.

## Federal / public sector (e.g. USAJOBS)
- Longer, detailed; include hours per week, supervisor, exact dates, and KSA/qualification evidence mapped to the announcement.
