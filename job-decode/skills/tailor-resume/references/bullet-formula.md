# Achievement bullet formula

**Strong verb + what you did + how/with what + measurable result + (scope/context)**

> Cut monthly close from 9 to 5 days by automating reconciliations in NetSuite across 4 entities.

## Verb bank by intent

- Built / created: Built, Designed, Launched, Developed, Established, Founded
- Improved: Reduced, Increased, Accelerated, Streamlined, Optimized, Raised
- Led: Led, Directed, Mentored, Coordinated, Managed, Headed
- Won / sold: Closed, Secured, Negotiated, Grew, Expanded, Won
- Cared / served (clinical, support, education): Treated, Supported, Taught, Resolved, Advised

Avoid: "Responsible for", "Worked on", "Helped with", "Involved in".

## Metric ideas by domain (when the user has numbers)

| Domain | Metrics |
|---|---|
| Engineering / IT | Latency, uptime, users, cost, deploy frequency, bugs, load time |
| Sales | Quota %, ARR, deal size, win rate, pipeline, new logos |
| Marketing | CAC, ROAS, MQL/SQL, conversion, traffic, revenue influenced |
| Finance | Close days, savings, variance, audit findings, forecast accuracy |
| Operations | Throughput, cost per unit, SLA, defect rate, safety incidents |
| Healthcare | Patients/day, readmissions, compliance %, wait times |
| HR / talent | Hires, time-to-fill, retention, engagement |
| Education | Pass rate, scores, enrollment, retention |
| Design / product | Activation, retention, task success, NPS |

If no number exists, use scope instead: team size, budget, users, regions, frequency.

## Length

1–2 lines each, 3–6 bullets for recent roles, 1–3 for older ones.
